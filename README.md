# Divine & Beast（祂 · 兽）

基于 **Curios API** 的 Minecraft **Forge 1.20.1** 饰品模组（当前版本 1.4.0）。

## 功能总览

### 1. 槽位与物品
- 基础槽位：「祂」`divine`、「兽」`beast`（各 1 格，始终可见）。
- 佩戴『祂』解锁 5 个时刻槽；佩戴『兽』解锁 7 个法则槽（默认 0 格，佩戴期间 +1）。
- 物品：『祂』『兽』×2 ＋ 时刻 ×5 ＋ 法则 ×7。

### 2. 『祂』体系（不变）
阶段一负面 5 项（逐件解除）＋ 时刻佩戴正面；阶段二「救赎」（5 件齐）。

### 3. 『兽』体系（三阶段 + 法则佩戴效果）
| 阶段 | 条件 | 文本 |
| --- | --- | --- |
| 诅咒 | 拯救六件有缺 | 生于奇迹，行于混沌 |
| 拯救 | 六件齐（不含『自我』） | 内生轮回，超脱永恒 |
| 自·我 | 七件全齐 | 生于轮回之内，超脱自我 |

**诅咒负面（逐件解除，缺失法则生效）**：至高＝攻击固定 1 ｜ 智慧＝非物理伤害翻倍 ｜ 生命＝治疗反噬 ｜ 混沌＝攻击 50% 落空+受击 50% 翻倍 ｜ 自我＝10 秒 +1 层（上限 88，每层 +2 吸收/+2 攻击，每扣 2 点吸收减 1 层）｜ 吞噬＝饱食无法恢复、饥饿每秒扣 2 ｜ 轮回＝复活无效、致命伤回出生点并损失 50% 当前生命。

**法则佩戴效果（本轮定稿，取代旧版正面；任何阶段生效）**：
| 法则 | 文本 | 效果 |
| --- | --- | --- |
| 至高 | 轮回之中，至高之神 | 攻击不造成普通伤害，而是**直接扣除目标等量生命（真伤）**；每次造成伤害 +1 层增伤（每层 +10%，最高 10 层，10 秒无命中清零） |
| 智慧 | 知一切，知过去，知未来 | 受到的所有伤害**减半**，并有 **90% 概率完全无效**本次伤害 |
| 生命 | 万生之母 | 任何来源的恢复**翻倍**；受到伤害时**回复该伤害一半的生命** |
| 混沌 | 一切终将混乱 | 攻击 90% 概率伤害翻倍；9% 概率造成**敌方最大生命 50%** 伤害；1% 概率造成 **99%** 伤害（后两者无视护甲） |
| 自我 | 一切轮回的主角 | 每次造成伤害或每 5 秒 +1 层（上限 **888**）；每层 **+20 吸收（吸收心）与 +20 攻击力**；每被扣 2 点吸收减 1 层 |
| 吞噬 | 行于混沌，吞噬混沌 | **饱食度>4 时伤害先由饱食度抵消**（1 伤害≈1 饱食，扣到≤4 停止）；饱食 0~4 不触发；**无饱食度（自·我：饱食度消除）时不受伤** |
| 轮回 | 四纪元终达毁灭 | 每 **(180 − 等级/10) 秒 +1 层轮回**（上限 100）；**死亡时消耗 1 层复活**，刷新冷却（本模组内：时刻5 复活等）并将叠层拉满（至高/自我）；死亡不掉落经验 |

> 数值"点/吸收心"=1 HP（可整体调参）。

## 构建 / 安装
JDK 17 + Gradle 8.1.1 + Forge `1.20.1-47.3.0`；Curios 依赖已启用。产物 `build/libs/divinebeast-1.4.0.jar`，与 Curios `5.14.1+1.20.1` 同放 `mods/`。

## 实现口径与边界（可随时调）
- 至高真伤/混沌概率伤害采用"无视护甲、按你为来源结算"的近似实现：以 `genericKill` 结算保证无视护甲与免伤；由此击杀的实体在**本模组"击杀奖励"里不计入击杀来源**（普通掉落/经验仍正常），如需击杀联动可再细化。
- 自我(法则)的 888 层吸收按"叠层时设定上限值、受击自然消耗、每扣 2 点减 1 层"实现（不会每 tick 自动回满）；数值极大属设计数值。
- 吞噬血盾仅食量 >4 触发（1 伤害 ≈ 扣 1 饱食）；自·我阶段"饱食度消除"= 始终无饥饿 + 吞噬判定为无饱食度 → 免疫伤害。
- 轮回的"刷新所有冷却"仅能可靠作用于本模组（时刻5 复活冷却、至高/自我叠层拉满）；其他模组技能/武器/法术冷却无法通用重置（尽量原则）。
- 智慧减伤（90%+减半）与吞噬免疫可能互相叠加成近免伤，属设计效果。
- 图标已接入：14 个物品与 14 个 Curios 槽位均使用程序生成的专属贴图（工具：`tools/generate_icons.ps1`，System.Drawing 矢量绘制 + 超采样）；如需精修美术可在同文件重绘后重跑。
- 英文文案仍待润色；未在本机 MC 实测，报错请贴日志。
